# 🔥 Лиса Гора

Вечіркова гра на 3–15 гравців українською: мапа на телевізорі (ноутбук), гравці — з телефонів. Шість ритуалів дорогою на вершину, набіги нечисті, дуелі, прокляття й обереги — і лише одна Верховна Відьма ночі.

**Завантажити:** https://ssatanyalomie.github.io/lysa-hora/

- [LysaHora-Mac.zip](https://github.com/ssatanyalomie/lysa-hora/releases/latest/download/LysaHora-Mac.zip) — Mac (Apple Silicon та Intel)
- [LysaHora-Windows.zip](https://github.com/ssatanyalomie/lysa-hora/releases/latest/download/LysaHora-Windows.zip) — Windows 10/11

Розпакуй → двічі клацни «Запустити гру» → гості сканують QR з екрана (в одному Wi‑Fi з ноутбуком) → перший, хто увійшов, натискає «Почати гру». Далі гра веде сама.

Бета-версія.
